# 并行程序设计课程作业：OpenMP Sobel

当前版本研究任务划分、共享任务池和同步机制，包含串行、静态分块、锁任务池、原子任务池四种自行实现。

`学号-姓名/`是提交目录：

- `代码/`：四种实现、独立参考测试、基准与诊断程序、复现和报告生成脚本。
- `报告/`：按模板重写的DOCX及PDF，详细说明设计依据、控制变量、同步正确性与实测分析。
- `实验结果/`：固定输入、全部输出、300条原始计时、汇总表、63条线程诊断记录、图表与环境信息。

`学号-姓名.zip`只包含提交目录。学号、姓名和学院班级留空，提交前填写并重命名。报告与图表的作者、编辑者等可编辑身份属性已置空。

本次串行均值57.914 ms；4线程静态28.866 ms、锁任务池19.610 ms、原子任务池21.021 ms。结论针对本次云端测量，不将程序整体排序当作同步原语成本排序。

复现命令见`学号-姓名/代码/README.md`。`temp/`收纳旧版实验备份、原模板、构建产物和检查中间文件，仅保留本地，不进入压缩包或Git提交。
